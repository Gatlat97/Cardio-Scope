# ❤️ CardioScope

## Overview

CardioScope is a machine learning project that predicts whether a patient is at risk of heart disease based on clinical and demographic health data.

## Dataset

This project uses the Heart Disease Dataset from the UCI Machine Learning Repository.

- 303 patient records
- 13 clinical features
- Binary classification problem

Dataset source:
https://archive.ics.uci.edu/ml/datasets/heart+disease
